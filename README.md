# 빅워시 현장

본사가 배정한 출장만 받아, 사진·명세·정산·경비를 본사에 남기는 직원 앱입니다.  
백엔드는 기존 HQ API입니다. 이 프로세스는 화면을 열고 API를 전달만 합니다.

## 실행

```bash
# 본사를 먼저 띄운 뒤 (기본 http://127.0.0.1:30000)
HQ_API=http://127.0.0.1:30000 npm start
```

브라우저: `http://127.0.0.1:40000`  
로그인 화면이 첫 화면입니다. 계정은 본사 `hq_users` 정규 직원입니다.

`TECH_PORT` 가 없으면 40000–49999에서 빈 포트를 고릅니다.  
`HQ_API` 를 생략하면 `http://127.0.0.1:30000` 을 확인하고, 본사가 없으면 종료합니다.

같이 띄우려면 본사 레포에서 `bash scripts/run-pair.sh`.

## 1차 범위

로그인, 오늘, 예정, 출장 한 장(장바구니·명세·사진·일지·완료·정산), 경비, 마감(퇴근/본사 회기), 설정(로그아웃·비밀번호).

## 하지 않는 것

고객 앱, 용병 가입, 일정 만들기, 상품 등록, 권역 단가 편집, 급여·운영비·보고, 본사 화면 복제.

## 본사가 받는 것

- `GET /hq/tickets?mine=1` 동행 포함
- 장바구니, 명세, 사진(base64), 정산 뱃지, 경비
- `POST /hq/tickets/:id/log` 출장일지
- `POST /hq/me/day-close` `clock_out` | `return_hq`
- `POST /hq/me/password`
